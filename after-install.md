# Celestial Court installed

Celestial Court works with **zero extra plugins** — the advocates' canons are built in.
The following *sharpening stones* make each side sharper. All are **optional**;
install them for full effect.

## CON arsenal (the Devil's side — minimalism, security, realism)

| Skill | Install |
|-------|---------|
| ponytail (YAGNI/minimalism ladder) | `/plugin marketplace add DietrichGebert/ponytail` then `/plugin install ponytail@ponytail` |
| code-simplifier | `/plugin marketplace add anthropics/claude-plugins-official` then `/plugin install code-simplifier@claude-plugins-official` |
| security-guidance | `/plugin marketplace add anthropics/claude-plugins-official` then `/plugin install security-guidance@claude-plugins-official` |
| grill-me (interrogate ambiguity) | `/plugin marketplace add reedom/mattpocock-skills` then `/plugin install grill-me@mattpocock-skills` |

## PRO arsenal (the God's side — design, innovation, potential)

| Skill | Install |
|-------|---------|
| frontend-design | `/plugin marketplace add anthropics/claude-plugins-official` then `/plugin install frontend-design@claude-plugins-official` |
| artifact-design / artifact-diagramming / dataviz | bundled with Claude Code — no install |

## Verify

Run `/celestialcourt-setup` anytime to check what's present and provision the rest
with your consent — never silently.

## Commands

- `/celestialcourt <suggestion>` — run an adversarial tribunal on a suggestion,
  argument, or caution
- `/celestialcourt-setup` — check/provision the arsenal
